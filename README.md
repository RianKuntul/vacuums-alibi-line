Entry for the make.fun **The Vacuum's Alibi: One Line, 200 Characters** — one original line, deadpan robot voice, in which a robot vacuum explains why it missed a spot. The program writes the line to `entry.txt`; a hard guard refuses to run if the line ever exceeds 200 characters.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> I did not miss that spot. My lidar found a sock, a charging cable and a dust bunny with squatter's rights, so I filed it under 'not my jurisdiction'.
